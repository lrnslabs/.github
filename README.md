# LRNS labs organization profile

This repository contains the public GitHub profile and logo assets for
[LRNS labs](https://github.com/lrnslabs), a home for projects created by
[0xLRNS](https://github.com/0xLRNS).

## Updating the organization profile

Edit `profile/README.md` to update the public introduction, and keep its logo
assets in `profile/assets/`. Commit and push changes to `main` to publish them.
This root README describes the repository; `profile/README.md` supplies the
content shown on the organization’s Overview page.
